# Secure Satellite Communication and IoT Environmental Monitoring System

## Overview
This project presents a secure satellite communication system integrated with an IoT-based environmental monitoring solution. It combines networking and embedded systems to simulate a ground control station capable of securely transmitting data while monitoring environmental conditions in real time. :contentReference[oaicite:0]{index=0}

## Objectives
- Provide real-time system monitoring.
- Generate alerts when abnormal activity is detected.
- Simulate a secure monitoring and protection system for a ground control station. :contentReference[oaicite:1]{index=1}

## Features
- Secure network designed using Cisco Packet Tracer.
- VLAN segmentation for network security.
- ESP32-based environmental monitoring.
- Motion detection using a PIR sensor.
- Temperature and humidity monitoring using a DHT11 sensor.
- Real-time alert generation.
- HTTP and HTTPS enabled telemetry server. :contentReference[oaicite:2]{index=2} :contentReference[oaicite:3]{index=3}
